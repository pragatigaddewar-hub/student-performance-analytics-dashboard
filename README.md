# Student Performance Analytics Dashboard

A Streamlit web app that collects a student's information and subject marks, then calculates performance metrics, assigns a grade, and visualizes results — with an option to download a summary report.

## Overview

This app takes student details (name, age, gender) and marks in four subjects (Python, SQL, Statistics, Pandas), then computes:
- Total and average marks
- Percentage
- Grade (A+ to E)
- Pass/Fail result
- Performance category (Excellent, Good, Average, Needs Improvement)
- Strongest and weakest subject
- A bar chart comparing subject-wise performance
- A downloadable text report summarizing everything

## Features

- Simple form-based input for student details and marks
- Automatic grade and performance calculation on submit
- Subject-wise bar chart visualization using Matplotlib
- Downloadable performance report (.txt)
